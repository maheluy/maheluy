## 🚀 Featured projects

### 🤖 AI & Machine Learning

| Project | What it does | Stack |
| --- | --- | --- |
| [**SQLChef**](https://github.com/maheluy/SQLChef) | Text-to-SQL agent that answers questions in Portuguese over the Olist e-commerce dataset. It generates, runs and self-corrects read-only SQL across 6 iterative versions (few-shot, self-correction, schema hints, reviewer). Reaches **93% execution accuracy** on a 100-question benchmark with a local 14B model. | Python · LangGraph · Ollama (Qwen2.5-Coder) · SQLite · Streamlit |
| [**FER_model**](https://github.com/maheluy/FER_model) | Real-time facial expression recognition from a webcam (8 classes, FERPlus). A compact AnyNet-style CNN (~650k params) trained from scratch, tuned with Optuna (TPE + median pruning) and paired with YOLOv8n-face for detection. | PyTorch · Optuna · Ultralytics YOLOv8 |
| [**Otimizador_Lookahead**](https://github.com/maheluy/Otimizador_Lookahead) | Empirical study of the Lookahead optimizer on top of SGD, Adam, Adagrad and RMSProp, fine-tuning a ResNet-18 on CIFAR-10 over 3 seeds. Lookahead + SGD gave the best result (**95.66%**), while adaptive optimizers became unstable. | PyTorch · ResNet-18 · CIFAR-10 · Jupyter |
